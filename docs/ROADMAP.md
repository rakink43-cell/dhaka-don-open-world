# DHAKA-DON OPEN WORLD — Roadmap

## Confirmed design
- Web game for mobile and PC
- Third-person camera
- Compact, expandable Dhaka-inspired map
- Offline single-player for first release
- Reference-video-inspired graphics
- Free-first workflow
